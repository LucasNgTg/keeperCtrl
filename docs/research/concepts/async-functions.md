# Funções assíncronas (async e await)

**DATA:** 10/10/2026

Permitem executar operações que dependem de resultados futuros, como requisições a servidores e leitura de arquivos, sem bloquear a execução das demais operações da aplicação. A palavra-chave async define uma função que retorna uma Promise, enquanto await permite aguardar a resolução dessa operação dentro da função.

Pode ser utilizado no carregamento dos dados dos jogos, especialmente em operações envolvendo a Fetch API.

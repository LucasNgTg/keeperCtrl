# Frameworks

**DATA:** 08/08/2026

Frameworks são estruturas de desenvolvimento que oferecem ferramentas, convenções e recursos prontos para facilitar a construção e a manutenção de aplicações. No desenvolvimento web, frameworks como React, Angular e Vue.js auxiliam na organização de interfaces, gerenciamento de estados, atualização de elementos da página e reutilização de componentes.

Além dos frameworks, existem bibliotecas especializadas em mecanismos de pesquisa, como o Fuse.js, que permite realizar buscas aproximadas (fuzzy search), identificando resultados mesmo quando os termos digitados não correspondem exatamente aos cadastrados. Outra possibilidade é implementar a pesquisa diretamente com JavaScript, utilizando métodos de manipulação de arrays e strings, como filter(), includes() e toLowerCase().

Podem ser utilizados para implementar a busca de jogos pelo nome, permitindo que os responsáveis encontrem rapidamente os títulos desejados. A utilização de bibliotecas ou frameworks poderia facilitar a implementação de funcionalidades mais complexas, enquanto JavaScript nativo permitiria desenvolver uma solução mais simples, sem dependências adicionais.

> [!WARNING] Optou-se por não utilizar frameworks ou bibliotecas, implementando todas as funcionalidades em JavaScript puro.
